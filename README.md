# TOMOAI Viral Title Skill

> **⚠️ 此为早期通用版，已停止维护。完整版已合并到 [tomoai-skills](https://github.com/NEKOINEKOI/tomoai-skills) 仓库的 [`tomoai-aiheadline`](https://github.com/NEKOINEKOI/tomoai-skills/tree/main/skills/tomoai-aiheadline) skill 中。**

## 这个 skill 是什么

公众号爆款标题生成器。基于五要素公式（流量关键词 × 冲突悬念 × 情绪钩子 × 数字 × 动词）和 23 种标题模板，为文章生成高打开率标题。

## 为什么不再维护

这个版本的方法论来自公开的通用标题公式，任何自媒体教程都能找到类似内容。

后续迭代出的 **tomoai-aiheadline** 才是真正自研的版本：
- 10 步流水线（通读 → 判型 → 提取「读者获得感」爆点 → 选公式 → 双流派写作 → 中文表达校对 → 终审 → 排序 → 交付）
- 自研「四驱动力」模型（信息力 / 情绪力 / 利益力 / 悬念力）
- 「读者获得感」爆点判据（拒绝作者自嗨 / 行业观察当主钩子）
- 踩关键词层级（大厂 > 产品 > 功能，冷门工具挂母公司）
- 两流派模型（搜索 SEO 型 + 超短冲突型）
- 基于 9000+ 条真实爆款提炼的对标库

**如果你要用，请装完整版** 👉 [`tomoai-aiheadline`](https://github.com/NEKOINEKOI/tomoai-skills/tree/main/skills/tomoai-aiheadline)
